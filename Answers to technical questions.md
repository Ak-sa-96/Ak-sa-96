2. How would you track down a performance issue in production? Have you ever had to do this?

To track a performance issue, I would:

Check logs (server logs, error logs).
Use tools like:
Browser DevTools (Network & Performance tab)
Monitoring tools (like New Relic, Datadog)
Identify slow areas:
Database queries
API calls
Large images or assets
Optimize:
Improve SQL queries (add indexes)
Reduce API response time
Compress images and files
Test again after fixes.

I have not handled a live production issue at scale yet, but I have debugged performance issues in projects like slow queries and page load delays.
